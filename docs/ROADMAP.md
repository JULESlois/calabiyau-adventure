## Phase 1 · 地形词汇(先补静态语言,反哺全部现有房间)

### 1.1 可破坏墙 `@` —— 量级 S,最高优先

- 近战/子弹命中若干下后碎裂,永久记录(WorldState 新增 `brokenWalls: Set<"room:col:row">`,
  存档格式与 crystals 同构,save.ts 白名单同步)。
- tileAt():未破坏的 `@` 按 T_SOLID;渲染带细裂纹提示(裂纹密度=已受击数)。
- 香奈美声呐被动扩展:脉冲范围内的 `@` 短暂描边 —— 侦察角色的定位再+1。
- check-maps 新规则:`@` 后面必须真的藏着东西(空腔/生成物),禁止装饰性假墙。
- 首批铺设:每区域 2-3 处,藏弦晶/晶尘/捷径短路。
- 测试:击碎→tile 转空→持久化→重进房间仍开;声呐描边。

### 1.2 碎裂平台 `!` —— S

- 站上 0.45s 后塌落,离房重置(房间运行时状态,不入档)。
- 渲染:踩上后抖动+落灰倒计时。测试:计时塌落、重入重置。

### 1.3 荆棘 `;` —— S

- 非致死减速带:接触掉 4 血 + 0.6s 减速 40%,不击退不弹起(与尖刺的"疼一下弹开"区分)。
- 用途:给"绕远 vs 硬闯"提供软选项。

### 1.4 冰面 `:` —— S

- 低摩擦地表:加速度 ×0.35、无输入滑行。constants 已集中,摩擦分支好做。
- 为后续 issue #39(坚冰滑轨)预留地基。

### 1.5 水体 `~` —— M

- 半高浮力区:入水减速 55%、跳高 -30%、可缓沉;**纸片形态入水立即强制展开**
  (纸会湿 —— 弦化与水互斥,这条规则给沉潮地窟补主题欠账并制造新谜题)。
- 沉潮地窟改造:泄流环三房 + 蓄水池注水;check-maps 校验水面必须有可站立出口。
- 测试:浮力物理、纸片入水强制展开、水下弦能不回复。

### 1.6 吊链 `|` —— M

- 无能力需求的纵向抓附(上下爬、跳离),补前期竖井手感;与贴墙(需 cling)区分:
  链是"作者放的路",墙是"能力开的路"。
- Player 新增 'chain' 微状态(不算弦化,不耗弦能)。

### 1.7 暗区(RoomDef.dark)—— M

- 房间级标记:视野缩为玩家周围半径 90px 辐射渐暗;香奈美声呐脉冲短暂全亮(issue #32 的一半)。
- 首批:研究区检修暗线、档案馆深处。渲染用遮罩层,不改碰撞。

**Phase 1 完成定义**:6 种新 tile 上线,≥20 处铺设,check-maps 新规则全部有效,测试 +10 以上。

## Phase 2 · 对话系统 + 潮汐游园(城镇)

### 2.1 对话基建 —— M(一次性投资,全部叙事受益)

- `render/dialogue.ts`:对话框覆盖层(复用 ornateFrame + wrapText),打字机逐字、
  按确认翻页、说话人名牌 + 程序化像素头像(16×16,风格同现有 portrait)。
- `game/npc.ts`:NPC 定义表 —— id、名字、头像绘制函数、站位动画、
  **对话按 world.flags 分支**(`lines: (world) => string[][]`)。
- PlayState 接入:NPC 走现有 interactables 管线(F 交互 → overlay 'dialogue');
  Overlay 联合 + pause/map 屏蔽,与商店同层级。
- 测试:分支选择、翻页、关闭后不吞输入。

### 2.2 潮汐游园区域 —— M

- 新 ZoneId `'haven'`:3 房(游园入口 · 灯街 · 望海台),**无敌人生成符,校验器强制**
  (check-maps 新规则:haven 区域出现敌人生成符即报错)。
- 挂在海滨:coast_start 左侧或 coast_walk 下方;与 coast 之间 1 个过渡房
  (满足现有"跨区必经过渡房"校验)。
- 新 LevelTheme:暖橙灯光 + 淡青海面 —— 全游戏唯一亮色调,情绪对比是功能不是装饰。
- 新 MusicCue `'haven'`:慢拍、大调、少打击乐(MUSIC_LIBRARY 加一条)。
- 信标 + 商店分号(见 2.4)。

### 2.3 城镇成长(5 级热闹度)—— S(最出彩,成本最低)

按现有 world.flags 渲染分支,**零新进度系统**:

| 级 | 触发旗标 | 可见变化 |
|---|---|---|
| 0 | 初见 | 空荡长椅、熄灭的灯串、一个 NPC |
| 1 | `rescue:kanami` | 灯串点亮一半、茶摊开张、+1 NPC |
| 2 | `boss:warden` | 音乐加声部、孩子出现、风车转 |
| 3 | `boss:arbiter` 或 `boss:gambit` | 夜市摊位、灯全亮、+1 NPC |
| 4 | `boss:guardian`(通关) | 烟花、全员到场、感谢对话 |

- 测试:各级 NPC 出场表与装饰计数。

## 风险

1. **美术工时主导**:温室/晶蚀/错景的瓶颈是程序化像素作画量,不是逻辑。排期按 M 往 L 估。
2. **中文可读性未实机验证**:对话系统上线前必须先实机确认 10px 中文在放大后的观感,
   否则整个 Phase 2 的文本量都建立在未验证的地基上。
3. **存档版本**:brokenWalls 等新字段沿用"可选字段 + 白名单校验"模式,不升 v3;
   若 Phase 3 需要不兼容变更,统一在 3.2 时升版并写迁移。
4. **测试节奏**:每 Phase 结束测试数应净增;地形类必须有物理行为测试,不接受只测构造。
