# 卡拉比丘 · 弦间冒险 (Calabiyau Stringbound)

《卡拉比丘》(Strinova) 同人**银河城式**横板动作冒险游戏 —— **纯 Canvas 渲染 + React 外壳 + TypeScript**,零图片素材、零游戏引擎依赖,全部像素美术与音效均由代码程序化生成。

美术为**恶魔城 / 神之亵渎式哥特像素风**:巨月与血色落日、城堡尖塔剪影、拱窗月光、石砖地形、烛火与飘浮余烬,多层视差纵深:

```
天空/天体 → 远景 0.15 → 中景 0.32 → 近景 0.55 → 内墙层 0.85 → 游戏场景 1.0 → 前景遮挡层 1.3
```

> 同人作品,非官方,仅供学习交流。

## 玩法(银河城结构)

世界由 **4 个场景 × 15 个互联房间**构成(类似神之亵渎:每个场景内多个房间,房间边缘互通),不再是线性关卡:

- **能力驱动探索**:开局只有跑跳与战斗。**弦化**(Shift 纸片化)、**矩阵适配**(纸片贴墙滑行 + 蹬墙跳)、**弦翼**(二段跳)散落在世界各处,取得后旧区域的弦膜门、竖井与高台随之解锁;**香奈美**被囚于研究区深处,救出后才能 Q 切换角色。
- **调弦台**(休息点):触碰即回满生命与弦能、写入存档;倒下后从最后调谐的调弦台重新出发。
- **地图屏**(Tab / I):按场景着色的房间图,标注已到访房间与调弦台位置。
- **弦晶 ◆** 为全局唯一收集品(拾取永久记录),部分需要后期能力回访取得。
- 流程:海滨长廊(弦化)→ 中央研究区(救香奈美 · 蹬墙跳)→ 天穹回廊(二段跳)→ 塔顶机库(Boss「守望者 MK-III」)。升降井是海滨↔研究区的攀爬捷径。

### 角色(按原作定位还原)

- **米雪儿**(欧泊 · 守护 · 猫主题召唤流):
  - 主武器「警探」:全自动速射步枪,命中短暂冰凝减速(按住 J 连射)。
  - 技能「喵喵卫士」(L,9 秒冷却):部署猫形炮塔(至多 2 台,10 秒),自动索敌射击并减速敌人。
  - 被动「猫踪喵迹」:攻击米雪儿的敌人会被**标记** 5 秒 —— 轮廓高亮、受到伤害 +30%。
- **香奈美**(剪刀手 · 先锋 · 情报型狙击手):
  - 主武器「谢幕曲」:**长按 J 蓄力**狙击,松开射出 —— 满蓄高伤且穿透;轻点为速射音符。
  - 被动「交响爆音」:每发子弹的**弹着点产生声呐**,标记附近敌人、造成微量伤害,并**显形隐藏平台**。
  - 技能「旋律回响」(L,10 秒冷却):掷出声呐镖钉附墙面,周期释放声波(显形+标记),歌声还会为附近的她自己缓慢回血。
- **隐藏平台**:世界里藏着只有香奈美的声呐能显形的弦能平台(闪着微光的位置),显形约 6 秒,通向隐藏弦晶。
- **下劈(pogo)**:空中 S+K 向下挥击,命中敌人、敌弹或尖刺会向上弹起并重置二段跳/空中冲刺——恶魔城式的连续弹跳。
- **相位突进**:寻获「相位突进」后按 U 或 ; 冲刺(空中限一次,落地/贴墙重置)。它藏在升降井顶部——从海滨灯塔下的弦膜门坠入即可发现。
- **晶尘 ✦ 与记忆芯片**:敌人死亡散落晶尘(自动吸取),Boss 大量掉落。研究区门厅的**引航者·诺笛**出售 4 种记忆芯片:强健弦芯(生命上限+25)、利刃回响(近战+30%)、快弦回路(弦能回复+40%)、晶尘磁石(吸取范围扩大)——购入永久生效。
- **晶源体**:逆弦化侵蚀诞生的有机敌人——**爆裂魔怪**(逼近后点燃引信自爆,趁引信闪烁时远离或抢先击杀)与**刺镰魔怪**(压低蓄力后高速突刺,侧跳或下劈应对)。
- **弦化**:按住 Shift 变成 2D 纸片 —— 敌弹穿身而过、可穿越粉色「弦膜」、(取得矩阵适配后)贴墙滑行与蹬墙跳。弦化持续消耗弦能(青色槽),不可攻击。
- **近战连段**(K):三段连击,第三段更高伤害,挥击可以击碎敌方子弹。

## 运行

需要 Node.js 18+。

```bash
npm install
npm run dev        # http://localhost:3000
```

生产构建:

```bash
npm run build      # 类型检查 + 打包到 dist/
npm run preview
```

世界数据静态校验(房间尺寸、生成点支撑、出口配对、能力推进可达性):

```bash
npx tsx scripts/check-maps.ts
```

## 架构

```
src/
  components/GameCanvas.tsx   React 宿主:挂载画布、整数倍缩放
  game/
    Engine.ts                 固定步长主循环、状态机、房间切换、调试钩子 (window.__CBQ__)
    Input.ts                  键盘输入(按下/按住语义)
    Audio.ts                  WebAudio 程序化音效 + 芯片音乐序列器(按场景配乐)
    constants.ts              所有手感参数(跳跃、重力、弦能消耗等)
    save.ts                   localStorage 存档 v2(整个 WorldState 序列化)
    world/
      world.ts                场景 + 房间图:网格建造函数生成的房间、出口定义、能力文案
      WorldState.ts           常驻世界状态:能力/旗标/弦晶/到访/重生锚,跨房间存续
    levels/levels.ts          tile 常量与 ASCII 解析器
    entities/                 Player / 四类敌人 / Boss / 子弹 / 拾取 / 粒子
    render/                   程序化像素美术、视差背景、HUD、props(调弦台/能力祭坛/香奈美)
    states/                   TitleState(继续/新游戏/说明)、PlayState(单个房间的玩法核心)
scripts/
  check-maps.ts               世界数据校验(含出口配对与能力推进 BFS)
  harness.ts                  无 React 冒烟测试外壳
```

关键设计:

- **房间即状态**:`PlayState` 只承载一个房间;跨房间的一切(能力、旗标、已拾取弦晶、地图到访、重生锚)住在 `WorldState`,由 `Engine` 持有并整体序列化到 localStorage。
- **出口图**:每个房间声明边缘出口(左/右/下 + tile 范围 + 目标房间与落点),`check-maps.ts` 静态校验落点合法性与"按能力推进的全图可达性"(BFS 到不动点)。
- **能力门**:弦膜(需弦化)、竖井(需蹬墙跳)、高台(需二段跳)都是地形本身,出口上的 `needs` 只是给校验器的注解。
- 物理为 tile AABB:横纵分轴移动 + 逐像素回退;单向平台只在"脚在平台上方且未按下落"时生效;弦膜 (`%`) 对纸片形态玩家不产生碰撞。渲染为 480×270 逻辑分辨率按整数倍缩放。

## 调房间 / 手感

- 想改房间:编辑 `world/world.ts` 里对应房间的建造代码(`rect`/`set`,图例见文件头),`npx tsx scripts/check-maps.ts` 校验。
- 跳跃参考:单跳可越约 2 格高 / 3 格宽沟;二段跳约 4 格高;蹬墙跳适用于宽 2~3 格的成对竖壁。
- 想改手感:所有参数集中在 `constants.ts`。
- 调试:浏览器控制台 `__CBQ__.goRoom('sky_gate')` 跳房间,`__CBQ__.grantAll()` 解锁全能力,`__CBQ__.info()` 查看状态。
