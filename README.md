# 卡拉比丘 · 弦间冒险 (Calabiyau Stringbound)

《卡拉比丘》(Strinova) 同人**银河城式**横板动作冒险游戏 —— **纯 Canvas 渲染 + React 外壳 + TypeScript**,零图片素材、零游戏引擎依赖,全部像素美术与音效均由代码程序化生成。

美术为**恶魔城 / 神之亵渎式哥特像素风**:巨月与血色落日、城堡尖塔剪影、拱窗月光、石砖地形、烛火与飘浮余烬,多层视差纵深:

```
天空/天体 → 远景 0.15 → 中景 0.32 → 近景 0.55 → 内墙层 0.85 → 游戏场景 1.0 → 前景遮挡层 1.3
```

> 同人作品,非官方,仅供学习交流。

## 玩法(银河城结构)

世界由 **6 个区域、57 个互联房间**构成。房间图包含 68 条连接、12 个独立回环与 17 个三向以上枢纽,目标是让普通首次探索形成约一小时流程,而不是依靠重复长廊延长时间:

- **能力驱动探索**:开局只有跑跳与战斗。**弦化**(Shift 地面纸片化 / 空中飘飞)、**矩阵适配**(E 吸附墙面后 W/S 自由移动)、**弦翼**(二段跳)、**弦闪**、**踏空蓄步**、**雷行电容**(均见下)散落在世界各处,取得后旧区域的弦膜门、竖井与高台随之解锁;**香奈美**被囚于研究区深处,救出后才能 Q 切换角色。
- **三场 Boss 战**:天穹 · 弦翼圣所的**回响守卫**(420 HP,两阶段)守着「弦翼」祭坛——弦能屏障在它倒下前封住壁龛,所以这场仗是二段跳的入学考试,全部攻势都只用纸化/攀附/突进躲得开;圣堂 · 巨管风琴的**弦相审判者**(560 HP,两阶段,可选)守着「踏空蓄步」祭坛 —— 攻击分**体积相**(青色弹花,弦化穿过)与**平面相**(粉色弦面波纹,**只打纸片形态**,普通形态毫发无伤),半血后双向合拢,是对形态切换节奏的一整场考试;它自己也会弦跃换位,展弦失衡吃 2 倍伤害,读招语言与镜弦猎兵一致。塔顶机库的**守望者 MK-III**(900 HP,三阶段)是终盘 Boss。
- **信标**(休息点):靠近后按 F 激活,回满生命与弦能并写入存档;倒下后从最后激活的信标重新出发。**再按一次 F** 才打开传送列表,且光标默认停在当前信标 —— 休息不会抢走画面。
- **暂停菜单**:↑↓ 选择、确认键执行;「回到信标」与「返回标题」都需要二次确认,战斗键在菜单里完全无效。菜单内可打开**操作说明**面板(按已取得的能力渐进显示按键、组合操作、已持有芯片),这是游戏内查询按键的入口。
- **提示跟随设备**:界面记住最近一次输入来自键盘还是手柄,所有提示文字随之显示 `F` 或 `R3`、`空格` 或 `A`。
- **地图屏**(Tab / I):按区域着色,显示已到访房间、信标、已走通的连接与捷径状态。**通往未到访房间的出口画成短桩**(青色可通行 / 金色能力不足 / **亮白脉冲 = 能力刚够、值得回访**),页脚计数「可回访 n」,仍有未拾取弦晶的房间打粉点,并附图例与「房间 n/57」进度 —— 拿到新能力后知道该回哪里。
- **弦晶 ◆** 为全局唯一收集品(拾取永久记录),在 8 / 18 / 30 / 42 枚时触发永久共鸣,依次提高弦能与生命上限。HUD 常驻显示**距离下一次共鸣还差几枚**。
- **永久捷径**:7 道升降闸/回程闸必须从远端路线抵达开关后按 F 开启,状态写入存档,把深层支线重新接回区域枢纽。
- **遗珍芯片**:四条深层支线各藏一枚商店无法购买的永久芯片,分别强化生命、飘飞、声呐与冲刺。
- **上升气流**:天穹区域的气流只托起空中 Shift 飘飞的纸片,不会让地面弦化或普通形态自动升空。
- **区域机关**:沉潮地窟的周期压力喷流会推动纸片;研究区终端切换极性弦膜;圣堂共鸣器按节拍显形平台;机库传送带改变地面战斗站位。**弦镜偏转**(研究区 · 标本观察廊):校准能束沿直线传播,玩家在菱形弦镜节点上**弦化**,纸片身体便成为弦面,把能束折转 90° 射向上方接收器 —— 充能约 1 秒后点亮 7 秒,显形通往高处弦晶的隐藏平台。能束无伤害,纯解谜。
- **连续切房**:相邻房间仍独立加载,但以 0.36–0.46 秒镜头滑动衔接;同区域会延续背景视差、环境动画、移动速度与弦化状态,HUD 固定不跟随画面滑动。
- **跨区过渡**:全部 9 条区域边界均经过专属过渡房,沿途渐变两侧色彩并交接标志性机关;隐藏的海滨坠井也有独立纵向过渡,不会直接跳换背景。
- 流程:海滨长廊(弦化)→ 沉潮地窟→ 中央研究区(救香奈美 · 矩阵适配)→ 天穹回廊(中 Boss「回响守卫」→ 二段跳)→ 塔顶机库(Boss「守望者 MK-III」)。弦声圣堂、走私暗港、云背档案馆与反应堆旁路组成可选探索环。
- **二段跳后的回访环线**:三条支线只在取得弦翼后才打得开,各自形成一个回到区域枢纽的闭环,给旧区域第二次探索的理由 —— 沉潮泄流环(泄流阀道 · 沉没回廊 · 泄流库房,压力喷流)、圣堂管风琴环(无声环廊 · 无字抄经室 · 巨管风琴,共鸣器节拍平台)、机库熔铸环(熔铸台 · 高空步道 · 弹药舱,传送带与上升气流)。每条环线各带一处支线信标。

### 角色(按原作定位还原)

- **米雪儿**(欧泊 · 守护 · 猫主题召唤流):
  - 主武器「警探」:全自动速射步枪,命中短暂冰凝减速(按住 J 连射)。
  - 技能「喵喵卫士」(L,9 秒冷却):部署猫形炮塔(至多 2 台,10 秒),自动索敌射击并减速敌人。
  - 被动「猫踪喵迹」:攻击米雪儿的敌人会被**标记** 5 秒 —— 轮廓高亮、受到伤害 +30%。
- **香奈美**(剪刀手 · 先锋 · 情报型狙击手):
  - 主武器「谢幕曲」:**长按 J 蓄力**狙击,松开射出 —— 满蓄高伤且穿透;轻点为速射音符。
  - 被动「交响爆音」:每发子弹的**弹着点产生声呐**,标记附近敌人、造成微量伤害,并**显形隐藏平台**。
  - 技能「旋律回响」(L,10 秒冷却):掷出声呐镖钉附墙面,周期释放声波(显形+标记),歌声还会为附近的她自己缓慢回血。
- **隐藏平台**:世界里藏着只有香奈美的声呐能显形的弦能平台(闪着微光的位置),显形约 6 秒,通向隐藏弦晶。
- **下劈(pogo)**:空中 S+K 向下挥击,命中敌人、敌弹或尖刺会向上弹起并重置二段跳/空中冲刺——恶魔城式的连续弹跳。
- **相位突进**:寻获「相位突进」后按 U 或 ; 冲刺(空中限一次,落地/贴墙重置)。它藏在升降井顶部——从海滨灯塔下的弦膜门坠入即可发现。
- **晶尘 ✦ 与记忆芯片**:敌人死亡散落晶尘(自动吸取),Boss 大量掉落。研究区门厅的**引航者·诺笛**出售 4 种记忆芯片:强健弦芯(生命上限+25)、利刃回响(近战+30%)、快弦回路(弦能回复+40%)、晶尘磁石(吸取范围扩大)——购入永久生效。
- **晶源体**:逆弦化侵蚀诞生的有机敌人——**爆裂魔怪**(逼近后点燃引信自爆,引信闪烁频率随倒计时加快,并画出爆炸半径圈)与**刺镰魔怪**(压低蓄力、镰刃亮起寒光后高速突刺,侧跳或下劈应对)。
- **弦蛭**:吸附在拱顶下的伏击者,只在玩家真正走到正下方时脱落,落地后贴地追击。抬头看一眼顶板就能提前发现它。
- **迫击晶**:固定炮座,装填期完全静止且炮口蓄光越来越亮,出膛的是三发**慢速重弹**——可以近战击碎,也可以走开,但不能站着不动。
- **镜弦猎兵**:中后期精英 —— **墙不是它的边界**。受压(连续命中)或被贴身时,它会弦化成一道紫色纸光掠向你的另一侧,落位瞬间的**展弦动作是失衡窗口**(受伤 ×1.6);行程中子弹、近战与接触全部穿过它。读它的出口、在展弦一瞬抢先输出,是这场博弈的答案。
- **逆弦犬**:**唯一能嗅到纸片形态的敌人**。锁定前有一次约 0.35 秒的嗅探起手(吻部火花),锁定后全身泛起逆弦辉光并高速扑击——弦化不再是万能的隐身衣。
- **弦闪**(可寻获能力,藏于沉潮 · 无名遗龛):敌弹临身的**一瞬**(约 0.14 秒窗口)弦化,即可擦开子弹 —— 触发白光环爆、返还少量弦能,并使**下一次攻击伤害 ×1.8**(射击或近战,谁先出手谁消费,充能 4 秒)。长按弦化挂机不算精准,不会触发。它把弦化从「按住就安全」变成有节奏的攻防切换。
- **踏空蓄步**(可寻获能力,击败圣堂 · 巨管风琴的弦相审判者后解封):在二段跳之上获得**按时间充能的第三跳**(虚步,约 6 秒充能,略低于二段跳高度)。关键在于**空中同样计时**:用飘飞、贴墙、pogo 把自己留在空中足够久,虚步会在不落地的情况下重新亮起 —— 时间本身成为空中移动资源。刻意不做无限空中跳:6 秒充能远长于任何单次滞空手段。
- **雷行电容**(可寻获能力,藏于研究区 · 检修暗线):持续奔跑、冲刺、飘飞、贴墙爬行都会**积蓄电荷**(约 2.4 秒充满,站桩缓慢漏电,满充时身上迸金色电花)。满充后用**任意攻击命中导能节点**即放电,点亮回路约 4.5 秒 —— 受电升降台只在通电期间运转。移动本身第一次成为探索资源:先读一条能保持运动的路线,再把电荷带到终点消费。
- **弦化**:地面按住 Shift 变成 2D 纸片,敌弹穿身而过并可穿越粉色「弦膜」;空中按住 Shift 切换为独立的风吹纸片飘飞状态,降低下落速度。取得矩阵适配后,靠近墙面按 E 主动吸附,以纸片形态用 W/S 自由上下移动;贴墙时 W/S 不触发跳跃,再次按 E 会向外蹬墙跳并脱离。三种弦化状态持续消耗弦能(青色槽),且不可攻击。
- **近战连段**(K):三段连击,第三段更高伤害,挥击可以击碎敌方子弹。

## 运行

需要 Node.js 18+。

```bash
npm install
npm run dev        # http://localhost:3000
```

开发服务器启动后可访问 `http://localhost:3000/art-preview.html`,并排检查两名角色的待机、奔跑、起跳、滞空、下落、落地、战斗与三种弦化姿态。

生产构建:

```bash
npm run build      # 类型检查 + 打包到 dist/
npm run preview
```

世界数据静态校验(房间尺寸、生成点支撑、出口配对、跨区过渡覆盖、能力推进、地图格、环路与枢纽预算):

```bash
npm run check:maps
```

提交前完整检查(类型、单元测试、地图、生产构建、调试入口泄漏):

```bash
npm run check
```

## 架构

```
src/
  components/GameCanvas.tsx   React 宿主:挂载画布、整数倍缩放
  game/
    Engine.ts                 固定步长主循环、状态机、房间切换、仅开发环境调试钩子
    Input.ts                  键盘与 Standard Gamepad 输入(按下/按住语义)
    Audio.ts                  WebAudio 程序化音效 + 芯片音乐序列器(按场景配乐)
    constants.ts              所有手感参数(跳跃、重力、弦能消耗等)
    save.ts                   localStorage 存档 v2(整个 WorldState 序列化)
    world/
      world.ts                场景 + 房间图:网格建造函数生成的房间、出口定义、能力文案
      WorldState.ts           常驻世界状态:能力/旗标/弦晶/捷径/到访/重生锚,跨房间存续
    levels/levels.ts          tile 常量与 ASCII 解析器
    entities/                 Player / 九类敌人 / 两场 Boss / 子弹 / 拾取 / 粒子
    render/                   程序化像素美术、视差背景、HUD、props、覆盖层界面、操作说明面板
    states/                   TitleState、PlayState、RoomTransitionState(连续切房镜头)与 regionMechanics(区域机关)
scripts/
  art-preview.ts              两名角色的动作矩阵预览
  check-maps.ts               世界数据校验(出口/地图/拓扑预算与能力推进 BFS)
  world-stats.ts              房间图与地图格占用速览(npm run stats [区域名…])
  find-slots.ts               列出可安全放置地面敌人的格位(npm run slots 房间id…)
  harness.ts                  无 React 冒烟测试外壳
```

关键设计:

- **房间即状态**:`PlayState` 只承载一个房间;跨房间的一切(能力、旗标、已拾取弦晶、地图到访、重生锚)住在 `WorldState`,由 `Engine` 持有并整体序列化到 localStorage。
- **实体依赖面显式化**:敌人与 Boss 只看到 `WorldApi`,玩家看 `PlayerHost`,部署物看 `GadgetHost`(全部定义在 `game/types.ts`)。实体不引用具体的 `PlayState`,因此依赖是单向的。
- **区域机关自成模块**:移动平台、上升气流、压力喷流、共鸣器、传送带、极性终端与捷径闸门都在 `states/regionMechanics.ts`,通过 `MechanicsHost` 回访房间;新增一种机关不必改动 `PlayState`。
- **覆盖层是纯绘制**:地图屏、商店、信标传送与暂停/死亡/能力/通关横幅都在 `render/overlays.ts`,操作说明在 `render/controlsPanel.ts`,两者每帧只从 `PlayState` 拿一份只读快照(`OverlayView` / `ControlsPanelView`),不持有房间状态。
- **提示文字与按键表同源**:`Input.ts` 同时导出 `KEYMAP`/`GAMEPAD_BUTTON_ACTIONS` 与 `actionLabel(action, device)`,界面一律通过它取按键名,改绑定不会让提示说谎。
- **存档只有一处校验**:`save.ts` 的 `parseWorldSave` 是唯一的信任边界,它返回带内部标记的 `ValidWorldSave`;`WorldState.deserialize` 只接受该类型,因此未校验的数据在类型层面就无法抵达。
- **连续但不常驻**:`RoomTransitionState` 在短时间内拼接前后两个冻结房间;结束后只保留新 `PlayState`,因此没有把全图常驻内存或重构为连续大地图。
- **出口图**:每个房间声明边缘出口(左/右/下 + tile 范围 + 目标房间与落点),`check-maps.ts` 静态校验落点合法性与"按能力推进的全图可达性"(BFS 到不动点)。
- **能力门**:弦膜(需弦化)、竖井(需蹬墙跳)、高台(需二段跳)都是地形本身,出口上的 `needs` 只是给校验器的注解。
- **Boss 只有一层契约**:`types.ts` 的 `BossLike` 定义了战斗结算、HUD 血条与部署物索敌需要的全部字段,`Boss`(守望者)与 `Warden`(回响守卫)各自实现;再加一场 Boss 战不需要改 `PlayState` 的战斗代码。
- **守卫屏障**:`RoomDef.bossGate` 声明一道由世界旗标(而非拉杆)解封的屏障,未解封时在 tile 层面等同实体砖 —— 这让「打赢守卫才拿到能力」成为地形事实,而不是靠 `needs` 注解约定。
- **区域结构**:参考《神之亵渎》的前段线性教学、多方向分支、跨区升降捷径和隐藏遗龛组织方式;没有照搬其完整体量。
- 物理为 tile AABB:横纵分轴移动 + 逐像素回退;单向平台只在"脚在平台上方且未按下落"时生效;弦膜 (`%`) 对纸片形态玩家不产生碰撞。渲染使用 480×270 逻辑分辨率,大屏整数倍放大、小屏等比缩小。

## 调房间 / 手感

- 想改房间:编辑 `world/world.ts` 里对应房间的建造代码(`rect`/`set`,图例见文件头),运行 `npm run check:maps` 校验。
- 跳跃参考:单跳可越约 2 格高 / 3 格宽沟;二段跳约 4 格高;贴墙移动适用于宽 2~3 格的成对竖壁。
- 想改手感:所有参数集中在 `constants.ts`。
- 调试:仅 `npm run dev` 开发环境会暴露 `window.__CBQ__`;可用 `__CBQ__.goRoom('sky_gate')` 跳房间、`__CBQ__.grantAll()` 解锁全能力、`__CBQ__.info()` 查看状态,生产构建不会暴露该入口。
