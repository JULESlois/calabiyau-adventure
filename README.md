# 卡拉比丘 · 弦间冒险 (Calabiyau Stringbound)

《卡拉比丘》(Strinova) 同人横板动作冒险游戏 —— **纯 Canvas 渲染 + React 外壳 + TypeScript**,零图片素材、零游戏引擎依赖,全部像素美术与音效均由代码程序化生成。

美术为**恶魔城 / 神之亵渎式哥特像素风**:巨月与血色落日、城堡尖塔剪影、拱窗月光、石砖地形、烛火与飘浮余烬,多层视差纵深:

```
天空/天体 → 远景 0.15 → 中景 0.32 → 近景 0.55 → 内墙层 0.85 → 游戏场景 1.0 → 前景遮挡层 1.3
```

角色带厚描边与待机/跑动/挥击细节动画,配合枪口焰、挥击弧光、弦化残影、受击红闪与全局暗角后处理。

> 同人作品,非官方,仅供学习交流。

## 玩法

扮演 **米雪儿** 与 **香奈美**,穿越欧拉的海滨长廊、中央研究区与天穹回廊,击败失控的巨型机甲「守望者 MK-III」。

- **弦化(纸片化)**:按住 Shift 变成 2D 纸片 —— 敌人的子弹会直接穿过你、可以穿越粉色的「弦膜」方块、可以贴墙滑行与蹬墙跳。弦化持续消耗弦能(青色槽),松开后回复。
- **双角色切换**(Q):
  - 米雪儿:冰霜手枪(单发高伤、命中减速),技能「冰霜新星」冻结周围敌人(L,9 秒冷却)。
  - 香奈美:音符三连发(扇形弹幕),技能「治愈旋律」回复 30 生命并获得短暂护盾(L,12 秒冷却)。
- **近战连段**(K):三段连击,第三段更高伤害,挥击可以击碎敌方子弹。
- 二段跳、单向平台(S+跳下落)、移动平台、尖刺、检查点、弦晶收集。

## 内容

- 第一关 · 海滨长廊(教学:移动、战斗、第一面弦膜)
- 第二关 · 中央研究区(炮塔、盾卫、弦膜密室、移动平台)
- 第三关 · 天穹回廊(高空跳跃、弦化蹬墙跳竖井、浮游炮)
- 最终关 · 塔顶机库(三阶段 Boss「守望者 MK-III」:践踏冲击波、扇形弹幕、蓄力冲撞、召唤浮游炮)

通关进度与最佳弦晶数保存在 localStorage,标题画面可选关。

## 运行

需要 Node.js 18+。

```bash
npm install
npm run dev        # http://localhost:3000
```

生产构建:

```bash
npm run build      # 类型检查 + 打包到 dist/
npm run preview
```

关卡数据静态校验(行宽、出生点、支撑面等):

```bash
npx tsx scripts/check-maps.ts
```

## 架构

```
src/
  components/GameCanvas.tsx   React 宿主:挂载画布、整数倍缩放
  game/
    Engine.ts                 固定步长主循环、状态机、调试钩子 (window.__CBQ__)
    Input.ts                  键盘输入(按下/按住语义)
    Audio.ts                  WebAudio 程序化音效 + 芯片音乐序列器
    constants.ts              所有手感参数(跳跃、重力、弦能消耗等)
    save.ts                   localStorage 进度
    levels/levels.ts          ASCII tile 地图(25 列分段拼接)+ 解析器
    entities/                 Player / 四类敌人 / Boss / 子弹 / 拾取 / 粒子
    render/                   程序化像素美术、视差背景、HUD
    states/                   TitleState(标题/选关/说明)、PlayState(玩法核心)
scripts/
  check-maps.ts               关卡数据校验
  harness.ts                  无 React 冒烟测试外壳
```

物理为 tile AABB:横纵分轴移动 + 逐像素回退;单向平台只在"脚在平台上方且未按下落"时生效;弦膜 (`%`) 对纸片形态玩家不产生碰撞。渲染为 480×270 逻辑分辨率按整数倍缩放,`image-rendering: pixelated`。

## 调关卡 / 手感

- 想改地图:直接编辑 `levels.ts` 里的 ASCII 段(图例见文件头注释),`npx tsx scripts/check-maps.ts` 校验。
- 想改手感:所有参数集中在 `constants.ts`。
- 调试:浏览器控制台 `__CBQ__.startLevel(3)` 跳关,`__CBQ__.info()` 查看状态。
